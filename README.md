# Authentication Guide

## Setup Instructions

### Requirements

Before setting up the project, ensure you have the following:

- **Python** installed on your system
- An **IDE** like **VSCode**
- A **browser** (e.g., **Chrome**)

### Project Setup

Follow these steps to set up the project:

1. **Unzip** the project folder to your preferred location (e.g., `Desktop/Authenticate`).
2. **Open** the Authenticate folder in **VSCode** or your preferred editor.
3. In **VSCode**, press `Ctrl + J` to open the terminal.
4. In the **VSCode terminal**, run the following commands:

   ```sh
   source venv/bin/activate
   ```

   This command activates the virtual environment.

   ```sh
   python manage.py runserver
   ```

   This command starts the development server.

5. Open your browser and visit:

   ```curl
   http://localhost:8000
   ```

6. 🎉 **Enjoy your authentication template!**
